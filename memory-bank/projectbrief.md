# DeepSlide — Project Brief

## Project Name
DeepSlide

## Purpose
AI-powered voice-controlled presentation app. Upload hundreds of images → AI extracts keywords → During live presentation, speaking keywords causes relevant slides to zoom fullscreen (Prezi-style).

## Core Problem
Traditional presentation tools (PowerPoint, Keynote) require manual slide switching. Speakers lose eye contact, lose flow, look unprepared. DeepSlide lets you present naturally — just talk, slides follow your voice.

## Key Differentiator
No competitor combines:
- AI keyword extraction from images
- Real-time voice recognition → slide matching
- Prezi-style smooth zoom (overview ↔ fullscreen)

## Target Users
- Conference speakers (tech talks, academic)
- Sales teams (product demos)
- Educators (visual teaching)
- Anyone with large image collections to present

## Core Features (Faz 1 - MVP)
1. Image upload + AI keyword extraction (Gemini/Qwen/Gemma)
2. Voice-controlled slide navigation
3. Prezi-style zoom presentation mode
4. 3 presentation theme presets
5. PDF/HTML export

## Monetization
- Free: 3 presentations, watermark, no export
- Premium: $15/month (iyzico), unlimited everything
- Market: Turkey first, global expansion planned
